# Deployment inventory and provenance

This inventory maps the PawGuide-owned state observed on the live China, X5,
and Hyper hosts on 2026-07-26 to a tracked source or an explicit external-state
requirement. It is the completeness checklist for rebuilding the deployment.

## Completeness rule

Every required runtime item belongs to one of these groups:

1. generated from this repository;
2. pinned by this repository and fetched during installation;
3. a credential or machine identity that must remain external;
4. transient state that is safe to regenerate.

An item not covered by one of those groups is a recovery defect.

## Deliberately external state

The repository does not contain:

- the Go2 AP password or Unitree AES key;
- operator or developer token values;
- SSH private keys;
- Tailscale enrollment credentials or node state;
- generated host keys, logs, caches, virtual environments, or old release
  wheels.

The recovery runbook gives the required location and regeneration or
installation step for each external input. No application behavior depends on
an undocumented secret value.
